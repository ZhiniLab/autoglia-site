# Development: The 6-Stage Retrieval Pipeline

1. **Context Classification** — Identify the type of interaction.
2. **Pathway Activation** — Check against known pathways.
3. **Candidate Retrieval** — Gather potential memory candidates.
4. **Ranking** — Score candidates dynamically.
5. **Bundle Assembly** — Inject structured memory bundles into responses.
6. **Post-Response Evaluation** — Review and improve based on user feedback.
