# Development: The 12 Memory Types Your Agent Needs

1. **Fact**  — Declarative statements that must be accurate.
2. **Preference** — User preferences, contextual style.
3. **Decision** — Record choices with justifications.
4. **Task** — Open-loop action items needing completion.
5. **Entity** — Important names, projects, or products.
6. **Pattern** — Recurring workflow that needs tracking.
7. **Failure** — Records of what didn’t work.
8. **Evidence** — Supporting documentation or verification artifacts.
9. **Inference**  — Agent conclusions subject to verification.
10. **Constraint** — Rules limiting actions or assignments.
11. **Goal** — Target objectives or end states.
12. **Workflow** — Preferred sequences of operation.
