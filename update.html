Open source

Stay up to date.

Autoglia is distributed from GitHub. Pull the latest code, then run migrations — no purchase email required.

Upgrade steps
  • Clone or pull — git pull in your checkout, or download a release.
  • Migrate — python3 migrate.py (or python3 ~/clawd/skills/memory-db/migrate.py if you use that layout).
  • Do not run setup.py install on top of an existing manual install unless you mean to — prefer copy files + migrate for upgrades.
Legacy customers

If you bought a zip in the past, you can move to the public repo anytime. Your memory.db is yours — back it up, then follow the same migrate path.
