# Development: Multi-Dimensional Memory Scoring

Memory should not be evaluated on a single axis. Use multiple dimensions to provide a blended perspective:

1. **Confidence Score** — Reliability based on history.
2. **Utility Score** — How often the memory leads to positive outcomes.
3. **Activation Score** — Balance of recent and frequent use.
4. **Stability Score** — Estimation of how persistent the fact remains.
5. **Cost Score** — Assessment of the expenses involved in usage.
